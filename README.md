# Anomaly Detection and Customer Segmentation

## Project Overview
This project focuses on anomaly detection and customer behavior analysis using unsupervised machine learning and deep learning techniques.

The project applies several algorithms to analyze high-dimensional transaction data, detect anomalies, and visualize hidden patterns.

---

## Dataset
The project uses the Credit Card Fraud Detection Dataset from Kaggle.

The dataset contains:
- More than 280,000 transaction records
- Numerical features
- Fraudulent and normal transactions

---

## Technologies and Libraries
- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- TensorFlow
- Keras

---

## Machine Learning Techniques
The following techniques were implemented:

- PCA (Principal Component Analysis)
- t-SNE
- DBSCAN
- One-Class SVM
- Autoencoder Neural Network

---

## Project Phases
1. Data Preprocessing
2. Feature Scaling
3. Dimensionality Reduction using PCA
4. Data Visualization using t-SNE
5. Clustering using DBSCAN
6. Anomaly Detection using One-Class SVM
7. Deep Learning using Autoencoder
8. Model Evaluation

---

## Results
The implemented models successfully detected anomalies and identified hidden structures within the dataset.

- DBSCAN identified clusters and noise points
- One-Class SVM detected anomalous transactions
- Autoencoder achieved strong anomaly detection performance using reconstruction error
